# Ground and road textures

Scanned materials from [Poly Haven](https://polyhaven.com), CC0 (public domain), packed into the
three texture arrays by `godot/tools/build/pack_ground.py` (1k maps; the salt crust is the cracked
mud bleached).

| Layer | Poly Haven material |
| --- | --- |
| 0 sand | dense_sand |
| 1 dirt | dry_ground_rocks |
| 2 rock | rock_face_03 |
| 3 salt crust | mud_cracked_dry_03 |
| 4 grass | leafy_grass |
| 5 snow | snow_02 |
| 6 forest floor | forest_ground_04 |
| 7 desert gravel | gravelly_sand |
| 8 asphalt | asphalt_02 |
| 9 road gravel | gravel_floor_02 |
