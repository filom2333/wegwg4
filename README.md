# Dust Road

A first-person survival driving game in the spirit of *The Long Drive*: an endless road running
north through desert, forest and snow, a car you keep alive part by part, and not much else.

The repository holds two versions of the game:

| Folder | What it is |
| --- | --- |
| [`godot/`](godot/README.md) | **The game**, being rewritten for Godot 4.7 in C#. Open `godot/project.godot` in Godot .NET 4.7. |
| [`web/`](web/README.md) | The browser version (three.js + Rapier). It is the reference the Godot version is ported from, part by part. Run `start-game.bat`. |

`HANDOFF.md` is the working log shared between the development sessions.
